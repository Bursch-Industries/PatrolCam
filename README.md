# Introduction
PatrolCam, is a technology taht empowers law enforcement to be both proactive and responsive. In an era where the integration of technology in policing lags behind other sectors. PatrolCam works to push for progress. Designed to bridge the gap between traditional policing methods and cutting-edge technology, PatrolCam utilizes the power of artificial intelligence and machine learning to enhance surveillance capabilities, streamline operations, and foster safer communities.


# Setting Up Local Development Environment for PatrolCam

---

## Step 1
Create a folder on your device where you want to store the local repository.

Example:
```bash
mkdir team-projects ( or whatever name you want )
cd team-projects
```

---

## Step 2
After getting access to the GitHub repository, run:

```bash
git clone <repository-url>
```
You can find the clone URL on the GitHub project page after clicking the grean code button (choose HTTPS or SSH).

---

## Step 3
Navigate into the cloned repository:

```bash
cd PatrolCam
```

In your IDE terminal, install the required dependencies by running:

```bash
npm install
```

---

## Step 4
Within the `PatrolCam` directory, create a `.env` file.

---

## Step 5
Open the OneDrive document (or other provided documentation) to find the required environment variables.

Copy and paste them into your `.env` file, and save that

---

## Step 6
Start the development server by running:

```bash
npm run dev
```

---

## Step 7
Open your browser of choice and navigate to:

```
http://localhost:3000
```
(or whichever port is shown in the terminal after starting the server).
